Music Genre Classification using Classical Machine Learning

This README presents the project in five structured passages, each focusing on a specific aspect of the system for clarity, technical depth, and recruiter readability.

1. Introduction and Overview

This project implements an end-to-end classical machine learning pipeline for music genre classification using the GTZAN dataset. The system converts raw audio signals into meaningful numerical features and applies an optimized machine learning classifier to predict music genres.

The project emphasizes machine learning fundamentals, feature engineering, and optimization techniques, intentionally avoiding deep learning models to build a strong baseline system.

Primary Objective: Classify music genres using engineered audio features and classical ML algorithms.

Core Assumption: Carefully designed features combined with optimized learning can achieve strong performance without deep learning.

2. Background and Context

Music genre classification is a challenging problem due to overlapping frequency patterns, noise in real-world audio, and variations in rhythm and tempo across genres.

The GTZAN dataset is a widely used benchmark in audio classification tasks and provides a controlled environment to explore feature-based machine learning approaches.

Historical Context: Traditional audio classification systems relied heavily on handcrafted features before deep learning became dominant.

Current Situation: Classical ML models remain valuable for interpretability, faster experimentation, and building strong baselines.

3. Core Arguments / Technical Position

This project is built on the position that classical machine learning pipelines remain highly relevant when supported by strong feature engineering and optimization strategies.

Argument 1: Audio features such as MFCCs and spectral statistics capture essential genre-related characteristics.

Argument 2: Optimization techniques like SGD with momentum significantly improve convergence and stability.

Argument 3: Classical ML models provide interpretable and reproducible results suitable for baseline systems.

4. Supporting Evidence and Implementation Details

The project validates its approach through structured implementation and evaluation using standard ML metrics.

Evidence for Feature Effectiveness: Aggregated MFCC, chroma, and spectral features successfully represent genre-specific audio patterns.

Evidence for Optimization Strategy: Momentum-based SGD improves training stability and generalization compared to naive gradient updates.

Model performance is evaluated using accuracy, precision, recall, F1-score, and confusion matrix analysis to identify genre-wise strengths and weaknesses.

5. Conclusion and Future Outlook

This project demonstrates that well-engineered classical machine learning systems can effectively solve audio classification problems and serve as strong baselines for more complex models.

Summary: An optimized classical ML pipeline can classify music genres using engineered audio features with interpretable results.

Next Steps: Extend the system with hyperparameter tuning, feature selection, ensemble methods, and comparison with deep learning approaches.
